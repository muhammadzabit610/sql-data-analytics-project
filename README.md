# SQL Data Analytics Project

## 📌 About the Project

This project focuses on exploring and analyzing data using **SQL** to find useful insights and understand business performance.

The data used in this project comes from my previous **Data Warehouse Project**. After building the data warehouse, I used the structured data for further analysis.

The main purpose of this project is to practice SQL for real-world data analysis and turn data into meaningful information.

## 🔍 What I Analyzed

In this project, I worked on:

* Exploring the database and understanding the data
* Creating important measures and KPIs
* Analyzing sales and business performance
* Finding trends over time
* Performing cumulative analysis
* Comparing different products and customers
* Segmenting data to find useful patterns
